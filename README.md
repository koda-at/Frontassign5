## Project Description

This project is a simple interactive profile website created using HTML and JavaScript. It demonstrates JavaScript objects, data types, arithmetic operations, event listeners, and DOM manipulation.

## Part 1: Profile Object, Data Types & Arithmetic

### Task 1: Personal Info Object

Created a JavaScript object named `userProfile` containing personal information such as name, birth year, developer status, and hobbies.

The object demonstrates different data types: string, number, boolean, and array.

### Task 2: Arithmetic Calculations

Used JavaScript to calculate the user's age dynamically based on the current year and birth year.

Also calculated the total number of hobbies using the array's `length` property.

The results are displayed in the browser console.

### Task 4: Event Listener

Implemented an event listener that responds when the user submits the form.

JavaScript reads the input values and updates the `userProfile` object.

The updated profile information, including the calculated age, is displayed on the webpage.


## Part 3: DOM List Manipulation

### Task 5: Creating & Removing Elements

Created an interactive hobbies list using JavaScript DOM manipulation.

- **Add Item:** Creates a new list element and adds it to the hobbies list.
- **Remove Item:** Removes the last hobby from the list.
- **Input Validation:** Prevents users from adding empty items.

The hobbies array is also updated when items are added or removed.
